# Unrot MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a polished mobile-first Unrot MVP with a 15-second practice, unlimited 60-second anonymous challenges, replaceable OpenAI voice/analysis providers, explainable divergence scoring, MongoDB persistence, and post-completion community comparisons.

**Architecture:** A Next.js TypeScript web client owns presentation, local drafts, recording, and anonymous history. A FastAPI service owns the curated challenge catalog, vendor-neutral provider ports, deterministic scoring, result access, and privacy controls; repositories support MongoDB in production and an in-memory implementation in tests. OpenAI-specific payloads stay inside provider adapters.

**Tech Stack:** Next.js, TypeScript, React, CSS Modules/global design tokens, Vitest, Testing Library, Playwright, FastAPI, Python 3.12, Pydantic, PyMongo AsyncMongoClient, pytest, HTTPX, OpenAI API, MongoDB.

**Spec:** `docs/superpowers/specs/2026-08-14-unrot-mvp-design.md`

## Global Constraints

- The hybrid print/cursive treatment appears only in the `Unrot` wordmark.
- Every other string uses a clean humanist sans with tabular numerals for timers.
- Voice is primary; typing is a complete fallback.
- Raw audio is never written to MongoDB, analytics, application logs, backups, or permanent storage.
- Community answers are inaccessible before a completed-attempt receipt is issued.
- OpenAI is selected by configuration behind `TranscriptionProvider` and `IdeaAnalysisProvider` ports.
- Anonymous play is unlimited and does not require authentication.
- Scores are creative feedback, never IQ, medical, or diagnostic claims.
- First-use practice lasts 15 seconds, requests three spoon ideas, is unscored, and advances with fewer than three.
- Full challenges last 60 seconds and never frame ten ideas as a pass/fail threshold.

```python
class ChallengeSummary(BaseModel):
    slug: str
    name: str
    description: str
    difficulty: Literal["easy", "medium", "uncommon"]
    theme: str
    art_key: str

def recommend_challenge(
    recent_ids: set[str], first_full_challenge: bool, seed: int | None = None
) -> ChallengeSummary:
    eligible = [item for item in CATALOG if item.slug not in recent_ids]
    if first_full_challenge:
        eligible = [item for item in eligible if item.difficulty != "uncommon"]
    return random.Random(seed).choice(eligible or list(CATALOG))
```

```python
class TranscriptionProvider(Protocol):
    async def transcribe(self, audio: bytes, mime_type: str) -> Transcript: ...

class IdeaAnalysisProvider(Protocol):
    async def analyze(
        self, object_context: ObjectContext, transcript: str
    ) -> IdeaAnalysis: ...

class Idea(BaseModel):
    raw: str
    canonical: str
    category: str
    valid: bool
    plausibility: float = Field(ge=0, le=1)
    elaboration: float = Field(ge=0, le=1)
```

The transcription route reads a bounded upload directly into memory, rejects unsupported MIME types and payloads over 10 MB, invokes the configured provider, clears the byte reference in `finally`, and never logs request bodies. OpenAI adapters map provider responses into these schemas. The local analyzer uses punctuation boundaries, normalized tokens, a small synonym map, and category keywords; it must remain deterministic.

```python
class ScoreBreakdown(BaseModel):
    total: int
    fluency: float
    flexibility: float
    originality: float
    plausibility_elaboration: float
    algorithm_version: Literal["1.0"] = "1.0"
    comparison_basis: Literal["reference-set", "blended", "community"]

def score_attempt(ideas: list[Idea], target_breadth: int, rarity_lookup: RarityLookup) -> ScoreBreakdown:
    valid = [idea for idea in ideas if idea.valid]
    fluency = 25 * min(1.0, len({idea.canonical for idea in valid}) / 10)
    flexibility = calculate_category_diversity(valid, target_breadth) * 25
    originality = mean(rarity_lookup.percentile(idea.canonical) for idea in valid) * 35 if valid else 0
    plausibility = mean((idea.plausibility + idea.elaboration) / 2 for idea in valid) * 15 if valid else 0
    return ScoreBreakdown.from_components(fluency, flexibility, originality, plausibility, rarity_lookup.basis)
```

Use cryptographically random receipt tokens, store only their hashes, enforce challenge matching, and make attempt creation idempotent. `MongoAttemptRepository` uses MongoDB indexes on challenge/date, anonymous-session/date, receipt hash, and idempotency key. Seed clusters stay distinguishable from community counts.
